# Rooftop Protocol

Platform/shooter in pixel art che gira interamente nel browser (un solo file HTML, nessuna build).

## Come giocare

Apri `index.html` in un browser, oppure servilo in locale:

```bash
python3 -m http.server 8000
```

e visita http://localhost:8000.

Su telefono compare un pad touch sotto lo schermo di gioco.
